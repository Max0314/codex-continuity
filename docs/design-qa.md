## 产品减法

主窗口只保留三层导航：

1. 会话：搜索、筛选、查看来源和在此设备继续；
2. 同步：当前状态、离线队列、最近活动和数据边界；
3. 设置：服务器、设备、工作根目录、凭据、主题和诊断测试。

托盘窗口只保留高频动作：立即同步、继续最近会话、自动同步、最近活动、打开主窗口、设置和退出。服务端管理页不再提供无法直接读取本机内容的“发布”按钮，只负责设备、令牌、密文快照、用户和客户端版本管理。

## 明确边界

- 不写入或覆盖 Codex 内部任务数据库；
- 不承诺把另一台电脑上的原生任务 ID 原样恢复；
- 项目代码仍由 GitHub/GitLab 同步；
- 远端任务通过加密快照、`HANDOFF.md` 和新任务入口可靠续接；
- 服务器没有共享加密密钥，不能读取会话正文；
- 自动升级签名、Windows 代码签名、容量配额、分片续传和企业安全审计仍属于发布前工作。
