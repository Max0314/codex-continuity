# ADR-0002：采用外部客户端 + 自有服务端

状态：已采纳
日期：2026-07-27
取代：ADR-0001 中“第一版必须采用 Plugin + Agent + Server”的结论

## 决策

第一版采用：

```text
Windows 单文件客户端 + Go 服务端 + React 管理网页
```

Skill、MCP、Plugin 均不作为核心依赖。

## 原因

- 用户明确选择外部工具方案；
- 需要独立于某一条 Codex 对话工作；
- 需要一次处理固定工作区根目录下的多个项目和多个任务；
- 需要断网队列、后台驻留、系统托盘和开机启动的演进空间；
- 个人服务器无法访问 Codex，但可以可靠保存客户端上传的密文；
- 后续扩展给同事时需要登录、用户隔离、设备令牌和管理界面；
- 即使 Codex 的 Plugin/MCP 接口变化，核心交接能力仍可用。

## 后果

- 第一版发布需要客户端 CLI 命令或未来的托盘按钮；
- 管理网页不能直接读取浏览器所在电脑的本地项目；
- 精确迁移原 Codex 任务 ID 不在承诺范围内；
- 后续可增加薄 Plugin/MCP 提升体验，但不得成为唯一入口。
