# Windows 桌面客户端

## 普通用户如何运行

普通用户不需要 PowerShell，也不需要安装 Go、Node.js 或 Rust。

1. 从服务端“桌面客户端”页下载 NSIS 或 MSI；
2. 安装后从开始菜单打开 Codex Continuity；
3. 使用用户名和密码注册或登录同步账号；
4. 第一台设备保存一次恢复密钥，其他设备直接登录即可；
5. 在“设置”确认设备名称和工作区根目录；
6. 完成连接与加密上传测试；
7. 关闭主窗口后，应用继续在托盘运行。

企业环境可以通过 MSI、Intune 或 SCCM 批量部署。正式分发前应配置组织代码签名。

旧版本升级账号时，客户端通过 Windows IP Helper 原生 API 读取物理网卡永久 MAC，不启动
PowerShell 或 getmac 子进程。若账号注册已经完成、但设备关联曾被网络
或旧设备记录中断，可以直接再次提交原注册信息；服务端会验证用户名、密码和本机同步密钥
摘要后恢复设备关联，不会创建第二个账号或替换原同步密钥。

## 主窗口

### 会话

- 读取与工作区根目录关联的 Codex 会话；
- 按标题、项目或来源设备搜索；
- 按项目、日期、已同步、可继续、等待上传等条件筛选；
- 从会话工具栏直接进入同步范围设置；
- 查看来源设备、目录映射、更新时间和加密大小；
- 在当前设备定位原生任务，或生成安全续接材料；
- 打开加密归档和导出离线备份。

### 同步

- 显示上次成功、下次检查和离线队列；
- 手动立即同步；
- 开关后台自动同步；
- 查看最近活动与数据安全边界。
- 导出不包含凭据、路径或会话内容的脱敏诊断报告。

### 设置

- 当前登录账号与连接安全状态；
- 设备名称；
- 固定工作区根目录；
- 账号恢复密钥查看与退出登录；
- 同步日期、项目、归档会话和无项目会话；
- 开机启动和自动同步；
- 蓝、青绿、紫三种主题；
- 连接测试和加密上传测试。

## 托盘快捷窗口

- 立即同步；
- 打开最近可继续的会话；
- 查看最近三条会话；
- 开关自动同步；
- 打开同步页、设置页和主窗口；
- 退出应用。

`Ctrl+Alt+P` 等价于“立即同步”。

## 本机数据

- 普通配置：Tauri 应用配置目录；
- 登录令牌、账号同步密钥：Windows Credential Manager；
- 离线队列：应用配置目录的 `outbox/`；
- 远端续接材料：`<工作区根目录>\.codex-continuity\handoffs\`；
- 手工导入材料：`<工作区根目录>\.codex-continuity\imports\`。

## 开发与构建

```powershell
.\scripts\dev-desktop.ps1
.\scripts\build-desktop.ps1
```

构建产物写入 `release/`。

忘记密码时，在登录页选择“使用恢复密钥”，输入用户名、恢复密钥和新密码。重置成功后，
其他设备的旧客户端会话会失效，需要用新密码重新登录。
