# Windows 桌面客户端

## 普通用户如何运行

普通用户不需要 PowerShell，也不需要安装 Go、Node.js 或 Rust。

1. 从服务端“桌面客户端”页下载 NSIS 或 MSI；
2. 安装后从开始菜单打开 Codex Continuity；
3. 在“设置”完成服务端、设备、根目录、令牌和共享密钥配置；
4. 完成连接与加密上传测试；
5. 关闭主窗口后，应用继续在托盘运行。

企业环境可以通过 MSI、Intune 或 SCCM 批量部署。正式分发前应配置组织代码签名。

## 主窗口

### 会话

- 读取与工作区根目录关联的 Codex 会话；
- 按标题、项目或来源设备搜索；
- 按已同步、可继续、等待上传等状态筛选；
- 查看来源设备、目录映射、更新时间和加密大小；
- 在当前设备定位原生任务，或生成安全续接材料；
- 导入和导出加密归档。

### 同步

- 显示上次成功、下次检查和离线队列；
- 手动立即同步；
- 开关后台自动同步；
- 查看最近活动与数据安全边界。

### 设置

- 服务端地址；
- 设备名称；
- 固定工作区根目录；
- 客户端 API 令牌；
- 共享加密密钥；
- 开机启动和自动同步；
- 蓝、青绿、紫三种主题；
- 连接测试和加密上传测试。

## 托盘快捷窗口

- 立即同步；
- 打开最近可继续的会话；
- 查看最近三条会话；
- 开关自动同步；
- 打开同步页、设置页和主窗口；
- 退出应用。

`Ctrl+Alt+P` 等价于“立即同步”。

## 本机数据

- 普通配置：Tauri 应用配置目录；
- API 令牌、共享密钥：Windows Credential Manager；
- 离线队列：应用配置目录的 `outbox/`；
- 远端续接材料：`<工作区根目录>\.codex-continuity\handoffs\`；
- 手工导入材料：`<工作区根目录>\.codex-continuity\imports\`。

## 开发与构建

```powershell
.\scripts\dev-desktop.ps1
.\scripts\build-desktop.ps1
```

构建产物写入 `release/`。
