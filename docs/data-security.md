# 数据与安全

## 服务端可见内容

服务端可见：

- 用户账号与角色；
- 设备名、操作系统、客户端版本和最后心跳；
- 项目/工作区标识；
- 快照状态、来源设备、时间和密文大小；
- 客户端 API 令牌前缀和 SHA-256 摘要。

服务端不可解密：

- Codex 会话正文；
- Git 补丁；
- `HANDOFF.md`；
- 密文包中的完整 manifest。

管理端展示的少量摘要由客户端作为元数据提交，不应在元数据中放置密码、密钥或聊天正文。

## 加密格式

客户端使用 32 字节共享密钥和 AES-256-GCM：

- 每份文件使用随机 96 位基础 nonce；
- 4 MiB 分块；
- 每个分块使用独立 counter nonce；
- 魔数和格式版本作为附加认证数据；
- 任意分块被篡改、截断或使用错误密钥都会解密失败。

共享加密密钥不上传服务端。两台电脑必须配置同一把密钥，才能读取彼此的快照。

## 认证与本机凭据

- 管理网页密码使用 Argon2id；
- 登录会话使用随机令牌，Cookie 为 HttpOnly、SameSite=Lax；
- HTTPS 环境设置 `CONTINUITY_COOKIE_SECURE=true`；
- 客户端 API 令牌只显示一次，服务端仅保存摘要；
- 每台电脑使用独立 API 令牌，丢失设备时只撤销对应令牌；
- API 令牌和共享密钥保存在 Windows Credential Manager；
- 普通设置、同步状态和离线队列保存在 Tauri 应用配置目录。

## 服务端文件

```text
/data/continuity.db
/data/blobs/*.ccx
```

容器使用非 root 用户运行。生产环境仍应启用主机磁盘加密、HTTPS 或私有 VPN、严格备份权限和最小暴露端口。

## 公司数据边界

即使会话正文已经端到端加密，把公司数据上传到个人服务器也可能受公司制度、客户合同、数据地域和审计要求约束。部署给同事前，应由公司确认私有服务器、密钥托管、保留周期和事故响应方案。

商用发布前还需要：

- 项目 allow/deny 规则；
- 敏感目录默认拒绝；
- 容量配额与自动清理；
- 审计日志和 API 限流；
- 数据备份/恢复演练；
- 密钥轮换和设备撤销；
- 多用户越权安全测试。
