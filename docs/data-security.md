# 数据与安全

## 服务端可见内容

服务端可见：

- 用户名、密码哈希、账号角色；
- 设备名、操作系统、客户端版本和最后心跳；
- 项目/工作区标识；
- 快照状态、来源设备、时间和密文大小；
- 为支持远端会话列表而单独提交的 manifest 元数据，包括会话标题、相对工作目录、
  修改时间、Git 分支、提交号和变更文件名；
- 客户端 API 令牌前缀和 SHA-256 摘要。

服务端不可解密：

- Codex 会话正文；
- Git 补丁；
- `HANDOFF.md`；
- 密文包内的 manifest、会话原始文件和补丁正文。

服务端数据库中的 `manifest_json` 是可读元数据，不是聊天正文密文。客户端不得在该元数据中放置
密码、密钥、聊天正文、补丁正文或源设备绝对路径。

## 加密格式

客户端使用 32 字节账号同步密钥和 AES-256-GCM：

- 每份文件使用随机 96 位基础 nonce；
- 4 MiB 分块；
- 每个分块使用独立 counter nonce；
- 魔数和格式版本作为附加认证数据；
- 任意分块被篡改、截断或使用错误密钥都会解密失败。

账号同步密钥本身不上传服务端。注册时，客户端使用密码经 Argon2id 派生包装密钥，再用
AES-256-GCM 封装账号同步密钥；服务端只保存盐值与封装后的密文。另一台电脑使用相同
用户名和密码登录后自动解锁，不需要复制共享密钥。

恢复密钥就是 32 字节账号同步密钥的可携带编码。服务端只保存它的 SHA-256 摘要，不保存
恢复密钥原文。忘记密码时，客户端先用摘要证明恢复密钥匹配，再用新密码重新封装同一把
同步密钥；服务端同时注销该账号的旧客户端会话。

“同步无项目会话”默认关闭。开启后，工作区根目录外的会话使用固定逻辑路径
`__unassigned__`，不会把源设备绝对工作目录提交到服务端。

## 认证与本机凭据

- 管理网页和桌面账号密码使用 Argon2id；
- 登录会话使用随机令牌，Cookie 为 HttpOnly、SameSite=Lax；
- HTTPS 环境设置 `CONTINUITY_COOKIE_SECURE=true`；
- 桌面端访问令牌有效期 15 分钟，刷新令牌有效期 30 天并在刷新时轮换；
- 令牌摘要保存在服务端，明文登录令牌与账号同步密钥保存在 Windows Credential Manager；
- 旧 API Token 仅用于原地迁移和未升级客户端兼容；账号认领或密码恢复后会撤销该账号的旧 API Token；
- 恢复密钥原文不上传服务端，找回密码时只提交 SHA-256 摘要和重新封装的密钥；
- 设备 ID 是 `用户 ID + 主物理网卡 MAC` 的 SHA-256，不上传原始 MAC；
- 普通设置、同步状态和离线队列保存在 Tauri 应用配置目录。

MAC 指纹是当前阶段的产品选择：更换主物理网卡可能产生新设备，虚拟机克隆也可能复制
硬件身份，因此它只代表设备记录稳定性，不作为认证凭据。

## 服务端文件

```text
/data/continuity.db
/data/blobs/*.ccx
```

容器使用非 root 用户运行。生产环境仍应启用主机磁盘加密、HTTPS 或私有 VPN、严格备份权限和最小暴露端口。

## 公司数据边界

即使会话正文已经端到端加密，把公司数据上传到个人服务器也可能受公司制度、客户合同、数据地域和审计要求约束。部署给同事前，应由公司确认私有服务器、密钥托管、保留周期和事故响应方案。

商用发布前还需要：

- 项目 allow/deny 规则；
- 敏感目录默认拒绝；
- 容量配额与自动清理；
- 审计日志和 API 限流；
- 数据备份/恢复演练；
- 密钥轮换和设备撤销；
- 多用户越权安全测试。
