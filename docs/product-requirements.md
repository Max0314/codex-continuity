# 产品需求

## 用户

- 日常使用 Codex 编码、分析；
- 在两台或多台 Windows 电脑之间切换；
- 同时维护多个 GitHub/GitLab 项目；
- 拥有一台无法访问 Codex/OpenAI 的私有服务器；
- 可能把服务扩展给公司同事。

## 核心任务

用户无需逐项目、逐会话手工发布，就能：

1. 看到固定工作根目录关联的 Codex 会话；
2. 自动把变化后的会话快照加密同步；
3. 离线时不丢失待上传快照；
4. 在另一台设备找到目标会话；
5. 本机已有任务直接定位，远端任务生成安全续接入口；
6. 明确知道哪些数据由 Git 同步，哪些由 Continuity 同步。

## 功能范围

### 桌面客户端

- 会话扫描、搜索、筛选、详情；
- 自动同步、手动同步、离线队列；
- 加密归档导入导出；
- 本机任务定位与远端上下文续接；
- 托盘、开机启动、单实例、全局快捷键；
- 配置、主题、连接测试、加密上传测试；
- Windows Credential Manager。

### 服务端

- Docker Compose 私有部署；
- 管理员/成员登录；
- 多用户强隔离；
- 每设备独立 API 令牌；
- 设备、会话快照、版本和存储管理；
- 端到端密文存储；
- Windows 客户端下载。

## 安全要求

- 服务端不访问 OpenAI、Codex、GitHub 或 GitLab；
- 服务端没有共享加密密钥；
- API 令牌只保存摘要；
- 客户端正文使用 AES-256-GCM 加密；
- 错误密钥无法解密；
- 导入和续接不覆盖目标工作区；
- 不同用户不能读取彼此的元数据或密文。

## 非目标

- 不迁移原生 Codex 任务 ID；
- 不写入 Codex 内部数据库；
- 不自动应用 Git 补丁；
- 不覆盖 dirty 工作树；
- 不替代 Git 代码同步；
- 不要求 Skill、MCP 或 Plugin。

## 成功标准

1. 普通用户全程不需要 PowerShell；
2. 两台电脑只需一次配置即可后台同步；
3. 离线产生的快照在网络恢复后自动上传；
4. 另一台电脑可以从标题、项目和来源设备找到目标会话；
5. 服务端无法读取会话正文；
6. 运行中的 Codex 对话不会被 Continuity 强制中断；
7. 所有主界面、托盘和管理端可见交互均有明确反馈。
